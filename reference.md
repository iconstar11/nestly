# Reference

## Deployment
- **Live site:** `https://iconstar11.github.io/nestly/` (GitHub Pages from `master` branch, root)
- **Repo:** `https://github.com/iconstar11/nestly`
- Build output (`index.html` at root) is committed — GitHub Pages serves from there

## Tools & services
- **URL shortening:** Bitly — shorten client page URLs before sending to hosts
- **Host outreach:** WhatsApp — primary channel for contacting leads and delivering pages
- **Lead sources:** Instagram ads, Airbnb listings, Facebook profiles

## Social / brand
- Project name: Nestly Africa
- Domain/scope: Africa-wide (not city-specific)
- Tagline: "Direct Booking Pages for African BnB Hosts"

## Competitors & inspiration
- Airbnb (the platform we're helping hosts diversify away from)
- Booking.com (same)
- Direct-booking page builders (e.g., Lodgify, Your.Rentals) — but none targeting Africa specifically

## Pricing (as of Aug 2026)
- Setup fee: 1× the host's nightly rate (one-time)
- Monthly retainer: ~20-25% of one night's rate (hosting + updates)
- Host gets commission-free direct bookings; page goes down if they stop paying

## Lead pipeline statuses
| Status | Meaning |
|---|---|
| `found` | Lead identified, not yet contacted |
| `contacted` | WhatsApp sent |
| `call_booked` | Call scheduled |
| `call_done` | Call completed, info collected |
| `page_live` | Page built and link sent |
| `paying` | On monthly retainer |
| `dead` | Not interested |
